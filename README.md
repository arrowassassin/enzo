# enzo

This repository previously held the Enzo AI-native developer workspace (Rust, egui/wgpu). That code was retired on 2026-09-02 and remains available in git history before commit `b1f0a3f`.

The repository now holds startup-opportunity research for the next project.

## Research

- [`docs/research/00-synthesis.md`](docs/research/00-synthesis.md) — cross-sector comparison, scoring rubric, ranked contenders, recommendation, and a 30-day validation plan.
- `docs/research/01–06` — sector reports: security/trust, gaming/entertainment, physical AI/edge, vertical industry, consumer/prosumer, AI infrastructure.
- `docs/research/07` — social-sentiment sweep (Reddit, X, Hacker News, Product Hunt, Indie Hackers).
- `docs/research/08` — investor theses (YC RFS, a16z, Sequoia, Bessemer, Menlo, Redpoint) and macro catalyst timeline.

Every factual claim in the reports carries a source link. Figures were gathered through indexed search extracts and should be re-verified before external use.
