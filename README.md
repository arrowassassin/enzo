# enzo

This repository previously held the Enzo AI-native developer workspace (Rust, egui/wgpu). That code was retired on 2026-09-02 and remains available in git history before commit `b1f0a3f`.

The repository now holds startup-opportunity research for the next project.

## Research

- [`docs/research/00-synthesis.md`](docs/research/00-synthesis.md) — cross-sector comparison, scoring rubric, twelve ranked contenders, recommendation, and a 30-day validation plan.
- `docs/research/01–08` — sector sweeps: security/trust/fraud, entertainment/media/creator, gaming, consumer utility, physical world, health/bio/science/education, enterprise/vertical B2B, infra/data/compute.
- `docs/research/09` — social-sentiment sweep (Reddit, X, Hacker News, Product Hunt, Indie Hackers).
- `docs/research/10` — investor theses (YC RFS, a16z, Sequoia, Bessemer, Menlo, Sapphire) and macro catalyst timeline through 2028.
- `docs/research/archive-v1-founder-biased/` — the first pass, which wrongly assumed a Rust/systems founder. Kept for comparison.

Every factual claim in the reports carries a source link. Figures were gathered through indexed search extracts and GitHub-hosted digests and should be re-verified before external use.
