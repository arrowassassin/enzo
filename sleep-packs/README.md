# Quire sleep-screen packs

Ready-made lock-screen art for the Xteink X3 running [Quire](../README.md), with a
clean rectangle left in every image where the firmware draws the live time. The
device downloads them straight from GitHub over HTTPS:

```
https://raw.githubusercontent.com/arrowassassin/enzo/main/sleep-packs/index.json
https://raw.githubusercontent.com/arrowassassin/enzo/main/sleep-packs/<pack>/pack.json
https://raw.githubusercontent.com/arrowassassin/enzo/main/sleep-packs/<pack>/NN.pbm.z
```

Every image is generated by `firmware/tools/quire-sleep` from a fixed seed, so the
whole folder can be rebuilt bit-for-bit with `cargo run -p quire-sleep` from
`firmware/`. Contact sheets of every pack are in [`preview/`](preview/).

## Format

### `index.json`

```json
{
  "version": 1,
  "format": { "pbm": "P4", "width": 528, "height": 792, "one": "ink", "z": "zlib" },
  "licence": "CC0-1.0",
  "packs": [
    { "id": "mountains", "name": "Mountains", "description": "…",
      "images": 5, "bytes": 261415, "bytes_z": 67285, "path": "mountains/pack.json" }
  ]
}
```

* `bytes` is the total of the uncompressed PBMs (what the card will hold);
  `bytes_z` the total of the compressed files (what the device downloads).
* `path` is relative to the index.

### `<pack>/pack.json`

```json
{
  "id": "mountains", "name": "Mountains", "description": "…", "licence": "CC0-1.0",
  "images": [
    {
      "file": "01.pbm", "z": "01.pbm.z", "bytes": 52283, "bytes_z": 13723,
      "title": "Dawn",
      "clock": { "x": 162, "y": 100, "w": 204, "h": 77, "style": "hero", "on": "paper" },
      "credit": "Generated by quire-sleep; CC0 1.0",
      "ink": 0.348
    }
  ]
}
```

### Images

* `NN.pbm` — binary PBM (`P4`), 528 × 792, rows padded to whole bytes, **1 = ink**.
  This is exactly what `quire_library::cache::read_pbm` reads and what the `/sleep`
  folder on the card expects, so a `.pbm` can also be copied to the card by hand.
* `NN.pbm.z` — the same bytes, deflate-compressed with a zlib header and Adler-32
  trailer (`miniz_oxide::deflate::compress_to_vec_zlib`). The device inflates it with
  its existing inflater (`Framing::Zlib`) and writes the PBM to the card.

### The clock slot

`clock` describes a rectangle the artwork keeps clean — all paper or all ink — sized
from the real font metrics so any `HH:MM` fits with padding. The firmware draws the
time on top of the image:

| `style`  | Font                            | Text style on `"paper"` | on `"ink"`         |
|----------|---------------------------------|--------------------------|--------------------|
| `hero`   | `quire_fonts::ui::hero()` 56 px | `TextStyle::INK`         | `TextStyle::PAPER` |
| `poster` | `quire_fonts::ui::poster()` 44 px | `TextStyle::INK`       | `TextStyle::PAPER` |
| `label`  | `quire_fonts::ui::label_bold()` 18 px, tracking 2 | `TextStyle::INK` | `TextStyle::PAPER` |

Centre the text horizontally in the slot (`x + (w - measure_text(font, time)) / 2`)
and put the baseline at `y + (h - (asc + desc)) / 2 + asc`, where `asc`/`desc` are
the digits' extent above and below the baseline (see `quire_sleep::slot::digit_extent`;
for the hero strike this is what `ClockSlot::baseline` returns). Redrawing the time
means repainting only the slot rectangle with its surface colour and drawing again, so
a partial refresh of that rectangle is enough.

## Contributing a pack

1. Add a module under `firmware/tools/quire-sleep/src/packs/` that renders each image
   onto a `Canvas` and returns an `Art` with its `ClockSlot`, and list it in
   `packs::all()`. Use only ink, paper and dithered grey — no anti-aliasing — and keep
   the ink density between 5 % and 70 % (the test checks).
2. Choose the slot with `ClockSlot::centered(cx, cy, style, surface)`: its size comes
   from the font, so it always fits `21:47`. Design the composition around that
   rectangle; the writer clears it to its surface as the last step.
3. Run `cargo run -p quire-sleep` from `firmware/` (add `--png DIR` to look at the
   result with a sample time drawn in), then `cargo test -p quire-sleep`.
4. Hand-made images are welcome too: any 528 × 792 `P4` PBM plus a `pack.json` entry
   with a clean slot works, as long as it is your own work or public domain.
